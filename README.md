# ICE Nice — نسخه اولیه فول‌استک

## امکانات پیاده‌سازی‌شده
- ثبت‌نام و ورود با گذرواژه هش‌شده
- نقش مالک و بازیکن با کنترل دسترسی سمت سرور
- انتخاب یک کشور آزاد هنگام ثبت‌نام
- ذخیره دائمی حساب‌ها، کشورها، خبرها، درخواست‌های دیپلماتیک و خریدها در دیتابیس
- پنل مالک برای تغییر رنگ/وضعیت کشورها و بررسی درخواست‌ها
- خبرگزاری؛ انتشار خبر فقط برای مالک
- شاپ با CIP (120T) و VIP (70T) و اعتبار آزمایشی
- فهرست عمومی ۲۰ کشور و فهرست کشورها
- صفحه نقشه به‌شکل فهرست رنگی؛ اتصال نقشه جغرافیایی واقعی هنوز لازم است

## اجرای محلی
1. نصب Python 3.11 یا جدیدتر
2. باز کردن ترمینال در پوشه پروژه
3. نصب وابستگی‌ها:
   `pip install -r requirements.txt`
4. تنظیم متغیرهای محیطی:
   - `SECRET_KEY` را به یک رشته طولانی و تصادفی تغییر دهید.
   - `ADMIN_USERNAME` نام حساب مالک
   - `ADMIN_PASSWORD` یک گذرواژه قوی با حداقل 12 کاراکتر
5. اجرا:
   `python app.py`
6. باز کردن `http://127.0.0.1:5000`

## انتشار آنلاین با Render
1. این پوشه را در یک مخزن خصوصی GitHub قرار دهید.
2. در Render یک Web Service از مخزن بسازید؛ Render می‌تواند از `render.yaml` استفاده کند.
3. متغیرهای `ADMIN_USERNAME` و `ADMIN_PASSWORD` را در تنظیمات سرویس وارد کنید.
4. برای داده‌های پایدار، یک PostgreSQL ایجاد و `DATABASE_URL` آن را به سرویس وب متصل کنید.
5. قبل از انتشار عمومی، `SECRET_KEY` قوی، پشتیبان دیتابیس و تنظیمات امنیتی را بررسی کنید.

## نکات مهم قبل از استفاده واقعی
- این نسخه کد پایه است و پیش از استفاده عمومی باید تست امنیتی و عملکردی شود.
- دیتابیس SQLite برای استقرار چندکاربره پایدار مناسب نیست؛ در انتشار آنلاین از PostgreSQL استفاده کنید.
- فهرست ابرقدرت‌ها در این نسخه یک فهرست اولیه برای بازی است و ترتیب آن باید با منبع و سال مشخص نهایی شود.
- نقشه جغرافیایی تعاملی واقعی هنوز وصل نشده؛ فعلاً صفحه نقشه وضعیت و رنگ هر کشور را نمایش می‌دهد.
- گروه‌ها فعلاً در بخش توضیحات فهرست شده‌اند و هنوز حساب/موجودیت قابل انتخاب مستقل ندارند.
- اعتبار شاپ مجازی و بدون ارزش پولی واقعی است.
- اولین مالک با متغیرهای محیطی ساخته می‌شود. برای تبدیل بازیکن به مالک از مسیر ثبت‌نام امکان انتخاب نقش مدیریتی وجود ندارد.
